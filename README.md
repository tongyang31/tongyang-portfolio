# TongYang Engineering Portfolio — Moving Space Edition

## Upload to GitHub / Cloudflare Pages
Upload `index.html` and `space-background.webp` **together into the root of your GitHub repository**, replacing the old index.html. Both filenames must remain unchanged. Commit changes to the branch used by Cloudflare Pages (usually `main`). If connected, Cloudflare will automatically publish the new commit.

## Features
- Space artwork as the backdrop; subtle slow background drift
- Continuous right-to-left moving star sprites and speed streaks (Canvas)
- Centered TONGYANG / ENGINEERING PORTFOLIO / MECHATRONICS ENGINEER title
- Blinking "PRESS ANYWHERE TO ACCESS DATABASE" prompt
- Click anywhere (or Enter/Space) to open menu
- Projects, Experience, Skills, About, Contact pages retained
- Reduced-motion preference supported
