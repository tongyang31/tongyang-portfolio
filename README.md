# Student Engineering Portfolio Base

A simple starter portfolio based on the Caddy Boys website style.

## Included

- Minimal landing screen
- Clickable rotating placeholder mark
- Pixel-game main menu
- 3-second loading transitions
- Placeholder pages for:
  - Projects
  - Experience
  - Skills
  - About
  - Contact
- Empty asset folders ready for future images, videos and models

## Deploy

Upload all files to a new GitHub repository, then connect the repository to Cloudflare Pages.

## Later

Replace the temporary landing mark with your own logo / 3D model and fill the placeholder sections with your personal details.
